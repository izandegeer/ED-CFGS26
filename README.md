# Entornos de Desarrollo · CFGS DAW 2025/26

> Coursework for the **Development Environments** module — 1st year of the *Desarrollo de Aplicaciones Web* (DAW) higher vocational degree (Alicante, Spain).

This repository collects the practical work for the module, focused on the tools and good practices that surround software development beyond just writing code: IDEs, version control, build automation and documentation.

## 🧰 What's covered

- **IDE & tooling** — project setup and workflow in IntelliJ IDEA.
- **Build automation** — Java projects managed with **Maven**.
- **Version control** — Git workflow (branching, commits, history).
- **Code documentation** — automatic API docs generated with **Doxygen**.
- **OOP practice** — a small object model (a *SpaceX rockets* domain with `Motor`, `NaveSpaceX` and `NaveTripulada`) used to practise inheritance and class design.
